# Spec 9 — Tools

Source: `EXECUTION_PLAN.md` Phase 9 and `CLAUDE.md` (Tools, Security).
Status: confirmed by the developer on 2026-10-06. Proposals 1–4 accepted as written. Proposal 5: the developer
considers the average the key number; the distribution is kept because the plan names it, and the tool description
tells the model to lead with the average and mention the spread only when the user asks about it.

## Goal

Three tools answer questions that have an exact answer in the database, so the model never has to guess them:
`filter_movies`, `compare_movies`, `rating_summary`. In this phase they are plain Python functions wrapped as
LangChain tools and tested on their own. Phase 10 lets the LLM choose and call them.

## Design decisions the plan does not state (confirmed)

1. **Errors are returned, not raised.** A tool returns `{"error": {"code", "message", ...}}` instead of throwing, so in
   Phase 10 the model can read the problem and recover (for example, ask which *Beauty and the Beast*).
   Codes: `INVALID_ARGUMENTS`, `MOVIE_NOT_FOUND`, `AMBIGUOUS_TITLE`, `TOOL_FAILED` (database error).
2. **Title matching:** case-insensitive exact title match, ignoring surrounding spaces. A year can be given as
   `"Beauty and the Beast (1991)"` to pick one of several. `MOVIE_NOT_FOUND` also suggests up to 5 titles that
   contain the text ("Dark Knight" → "The Dark Knight", "The Dark Knight Rises").
3. **`filter_movies` arguments:** all three are optional, but at least one is required. `genre` must be one of the 17
   genres in our data (case-insensitive). Results are sorted by IMDb rating, best first, and capped at **10**
   (`limit` 1–25, default 10), with the total match count returned so the model knows when there are more.
4. **Which "rating":** `filter_movies` and `compare_movies` use the IMDb rating (`movies.rating`), the one a
   "which is rated higher" question usually means. `rating_summary` uses the critic review scores (normalised to 0–10).
5. **Rating distribution:** five 2-point buckets `0–2, 2–4, 4–6, 6–8, 8–10`, plus the number of reviews with no score.
   Counts cover the reviews in our dataset (14–20 per movie), not every review that exists; the result says so.

Full backend suite: 110 passed, 0 skipped.

Manual run on the real data (no API calls):
- `compare_movies("Zodiac", "Prisoners")` → Zodiac 2007, IMDb 7.7; Prisoners 2013, IMDb 8.2; 20 reviews each; higher: Prisoners.
- `rating_summary("Prisoners")` → average critic rating 7.19 from 20 reviews; buckets 0/0/2/10/8.
- `filter_movies(year_min=2010, genre="Thriller", rating_min=7.5)` → 28 matches, top 10 returned (The Dark Knight Rises 8.4 first).
- `rating_summary("Beauty and the Beast")` → `AMBIGUOUS_TITLE` with 1991 and 2017; `"beauty and the beast (1991)"` → average 8.48.
- `compare_movies("Dark Knight", "Inception")` → `MOVIE_NOT_FOUND` for `movie_a`, suggesting The Dark Knight and The Dark Knight Rises.
- `filter_movies(genre="cyberpunk")` → `INVALID_ARGUMENTS` listing the valid genres, no query run.
