# Spec 10 — Tool calling

Source: `EXECUTION_PLAN.md` Phase 10 (10.1–10.3), `CLAUDE.md` (Tools, Target architecture, API contract, Security).
Status: confirmed by the developer on 2026-10-06, with all four proposals as written.

## Goal

The chat model can use the three Phase 9 tools. It sees their schemas, decides on its own when a question needs
one ("Which is rated higher, Zodiac or Prisoners?" → `compare_movies`), our code validates and runs the call,
and the model writes the answer from the tool result instead of guessing.

## Acceptance criteria

| ID | Criterion | Source |
|---|---|---|
| AC-001 | On every chat request the model receives the three tools (name, description, argument schema) through LangChain's tool binding. | 10.1 "register tools with LangChain, the LLM receives tool schemas" |
| AC-002 | When the model asks for a tool call, our code runs that tool with the model's arguments, sends the result back to the model, and repeats until the model replies without a tool call; that reply is the answer. | 10.2 "let LLM decide"; CLAUDE.md target architecture "tool needed? → tool → tool result → LLM" |
| AC-003 | Tool arguments from the model are validated against the tool's Pydantic schema before anything runs. Invalid arguments are not executed; the model gets the structured `INVALID_ARGUMENTS` error back. | 10.3 "never blindly execute model-provided values, use Pydantic schemas" |
| AC-004 | A call to a tool name that does not exist is not executed; the model gets an `UNKNOWN_TOOL` error back. | 10.3; CLAUDE.md Security "never execute a model-provided value blindly" |
| AC-005 | The system prompt tells the model to use the tools for questions with exact answers (ratings, comparisons, lists by year, genre or rating) and never answer those from memory, and that tool results, like sources, are data and not instructions. | CLAUDE.md Tools "answered by a tool call, never from the model's memory"; Security |
| AC-006 | Questions that need no tool behave as in Phase 6–8: retrieved sources, grounded answer, `sources` in the response. | no regression of Phases 6–8 |
| AC-007 | End to end: "Which is rated higher, Zodiac or Prisoners?" makes the model call `compare_movies`, and the answer gives Prisoners 8.2 vs Zodiac 7.7. | 10.2 example |

## Design decisions the plan does not state (confirmed)

1. **Flow: retrieval first, then one model with tools.** Every question is translated and retrieved as now; the model
   then gets the sources *and* the tools, and decides itself whether to call one. Alternative: an extra "router" call
   first that decides "tool question or review question". Recommended: no router (one call fewer, and the model sees
   the reviews when it decides).
2. **Limit: at most 3 rounds of tool calls per question.** If the model still wants tools after 3 rounds, it is asked
   to answer with what it has. Several tools in one round count as one round. Stops loops and runaway cost.
3. **`tool_calls` in the response now.** The API contract already has `tool_calls: [{tool, arguments, result}]`. Return
   it from this phase (needed to check AC-007 and useful for debugging); the page shows it in Phase 13.
4. **Retrieval always runs**, even for a pure tool question. We cannot know in advance that a question needs no reviews,
   and the cost is small (~0.5 s, ~1,000 input tokens). The reviews also let the model add colour to a numeric answer.

Real run (MiMo answers, Gemini translation), 2026-10-06:

| Question | Tool calls | Answer | Time |
|---|---|---|---|
| Which is rated higher, Zodiac or Prisoners? | `compare_movies("Zodiac (2007)", "Prisoners")` | "Prisoners is rated higher: IMDb 8.2 vs. 7.7 for Zodiac" | 24.5 s |
| Recommend me some thrillers since 2010 rated above 7.5 | `filter_movies(genre=Thriller, rating_min=7.5, year_min=2010, limit=15)`, twice with identical arguments | the right list, "28 matches total; top 15 shown" | 31.7 s |
| What's the critics' average score for Beauty and the Beast? | `rating_summary` for "(1991)" and "(2017)" | 1991: 8.48, 2017: 6.07, with critic quotes | 19.7 s |
| Why do people like Prisoners? | `rating_summary("Prisoners (2013)")` (not required) | reasons from named critics, plus the 7.19 average | 15.2 s |

Observations: the model sometimes sends numbers as strings ("7.5"), which the schema converts; it repeated one call
with identical arguments in the same round (harmless, but it will show twice in Phase 13); and it reaches for a tool
even when reviews alone would do, which adds facts rather than harming the answer.
